<h1 align="center">🧰 Apps 🧰</h1>

<p align="center">
Small real apps made with goome, ready to download and use. Each one is a single <code>main.c</code> with the one goome header, and CI builds them for every desktop on every release.<br> <br>
Downloads are on the <a href="https://github.com/goome-ui/examples/releases/latest">latest release</a>.
</p>

| app | what it does |
|---|---|
| [goome-hud](goome-hud) | CPU, RAM, network and temps in a corner, drag it by the handle, clicks go through the rest |
| [crosshair](crosshair) | crosshair overlay with styles, colors and a settings window |
| [sticky](sticky) | sticky notes over your desktop, pinned or click-through, saved to a file |
| [keyviz](keyviz) | shows your keys and clicks for tutorials and recordings |

<p align="center">
<code>scripts/package-apps.sh</code> builds them and makes the zips the same way the release does.
</p>
